# Third-party materials

Owned implementation uses Apache-2.0. Installed NumPy, Pillow, OpenCV and optional
browser/model libraries keep their upstream licenses. BrowserGym, MiniWoB,
WebArena and model weights are external inputs; their implementations and model
caches are not vendored. Frozen episode records retain their benchmark and model
identities. Consult the upstream terms before obtaining original task sources.
